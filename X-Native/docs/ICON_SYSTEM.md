# X-Native icon system

X-Native uses an original, neutral outline icon family designed for dense desktop chrome.

## Geometry

- 18 x 18 px view box
- 1.45 px default stroke
- Round caps and joins
- 2 px optical corner radius
- 36 x 36 px toolbar cell with a 28 x 28 px active surface
- Muted graphite default; Electric blue or white-on-blue active state

## Primary set

- Move
- Frame
- Section
- Shape
- Pen
- Text
- Image
- Hand
- Comment
- Search / quick actions
- Present
- Share
- Visibility
- Lock
- Add
- Alignment and distribution

Icons are rendered as vector paths in the Vello shell. Emoji, platform symbol fonts, filled pictograms, and mixed icon families are intentionally excluded.

## Product distinction

The centered command group combines the speed of Framer-style creation controls with a Figma-style layer and property workflow. The Graphite capsule, Electric blue selection treatment, local-file identity, and integrated Code mode keep X-Native distinct.
