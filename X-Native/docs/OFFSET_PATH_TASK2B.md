# Phase 2 · Task 2B — signed filled-path offset

> **Bounded V5 session slice.** [CI run 36384662971](https://github.com/Ankushui18/X-native/actions/runs/36384662971) passed the Rust gate, Web tests/build, software-Vulkan screenshots and the **genuine generated-WASM offset corpus (30/30)** *with the pre-promotion guard still on*. Only after that evidence was the default offset oracle removed from the opt-in session. The final post-promotion run must also pass; this result does **not** promote the normal TypeScript editor, Auto Layout or general document persistence.

## Rust geometry, one history owner

- `x-core::offset_path::offset_filled_path` offsets **filled closed contours**: positive distance expands, negative distance insets. Rectangles, flattened ellipses, polygons, stars and bounded vectors all use the same signed geometry routine. It normalizes self-crossing and compound source paths under **NONZERO** winding before offsetting. That yields correctly oriented outer boundaries and holes, clips intersecting offset edges and discards collapsed insets rather than returning inverted contours. A closed figure-eight inset is tested separately from the rectangular-hole corpus.
- Miter (4× limit with bevel fallback), bevel and round (15° arc steps) derive from the requested stroke join. The overlay library's default **i32 integer solver** is used for both normalization and offsetting; its i64 outline splitter trapped with a WASM out-of-bounds memory error even on a rectangle. Inputs and output anchors/coordinates are capped, malformed/open/nonfinite paths are rejected, and all distances are finite, nonzero and at most 2048 in magnitude. The legacy web `geometry.ts::offsetPath` averaged-normal helper is *not* a filled-path oracle: it cannot model winding, holes or self-crossings.
- The web-compatible Boolean raster tracer can visit an inner boundary in the same direction as the outer boundary. A web vector's region uses EVENODD; native `.x` vector rendering and offset use NONZERO. The **Rust session's committed Boolean vector** reverses only nested contours whose winding disagrees with their parent, preserving the first anchor, filled cells and bounds. This does **not** alter the already-proven x-geo raw raster/TS parity contract. Native regression tests check that a Boolean-cut hole remains hollow after a bevel inset and Rust undo restores it.
- `x-editor::Editor::offset_filled_node` replaces **one** node in its existing undo stack. Pure `preview_filled_offset` proposes the exact same geometry without mutating history; undo/redo restore the original shape, style and sibling position. `x-editor::DocumentSession::Offset` is a bounded V3 command operation. The independently versioned **V5** `x-wasm` session ABI exposes `getShape`, `previewOffset` and `offsetNode` for just the affected layer; it never returns an entire page on edits. A whole `.x` transfer occurs only at admission or an **explicit** checkpoint/download. The native path uses the same Rust editor, not a parallel TS history.

## Web boundary and audit

The `#/file/<id>?engine=rust` view remains **opt-in**, one-page, direct-child, flat/solid/opaque and non-autosaved. It admits plain rectangles, ellipses, polygons and stars; only a vector created by the session is eligible for subsequent offset. It paints the returned vector and preserves Rust undo/redo. Unsupported styles, structures, curves and attributes are declined rather than copied into a shadow document or silently projected away.

After the genuine-WASM 30/30 guard-on result, ordinary offset edits in this admitted slice dispatch the **Rust command directly**, without fetching a TS reference or a second pure preview. Strict ABI, schema, typed bounded delta, affected-layer identity and checkpoint checks still apply. `?offset=audit#/file/<id>?engine=rust` opts into the independent coverage diagnostic: a bounded Rust shape/preview is compared under NONZERO winding **before** mutation; a rejection leaves history unchanged and other edits usable. The reference probes rectangle join corners analytically, checks prominent star miter tips against offset-edge intersections, and samples signed coverage away from inconclusive join wedges. It is **not** another document engine, renderer or undo system. If a post-commit delta contradicts the audited preview, editing pauses rather than falling back to a second owner.

## Proof and limits

The real-artifact smoke covers **five kinds × three joins × two signs = 30**: rect, ellipse, six-sided polygon, five-point star and a native-produced hollow vector; miter/bevel/round and +4/−4. Every case checks independent TS coverage after the Rust edit, bounded affected-layer deltas, identity, paint and an explicit lossless checkpoint. The vector cases assert opposing outer/hole winding and a surviving hole after both signs. Invalid distances leave the native revision unchanged. Undo/redo, one explicit audit and 29 direct native edits are exercised; a separate self-crossing vector inset checks disconnected lobes and NONZERO fill. Rust geometry/editor tests also cover reversed winding, collapsing insets, all three joins and history. Mock DOM tests verify UI, audit rejection and command wiring only; they do not stand in for the genuine WASM corpus.

**Still withheld:** production `MemoryEngine`/normal-editor migration, arbitrary styled/transformed/nested paths, SVG cubic vector checkpointing, open-chain outlining, text and variable-width strokes, full-document/Auto Layout parity and autosave. Their own admission and equivalence evidence are separate tasks.
